**Reservation System with Website**
===============================

**Module 01: Reservation / Booking System**
-------------------------------------------

A fully customized PHP-based reservation system designed to replace the previous WordPress booking solution, providing a faster, more secure, and feature-rich booking experience.

**Features**

*   **User Registration & Authentication**
    
    *   Secure user registration and login.
        
    *   Passwords stored using secure hashing algorithms.
        
    *   Only authenticated users can make reservations.
        
*   **Table & Facility Booking**
    
    *   Reserve tables or facilities by selecting:
        
        *   Reservation date
            
        *   Time slot
            
        *   Number of guests
            
    *   Real-time booking validation based on availability.
        
*   **Booking Management**
    
    *   View reservation details.
        
    *   Track booking history.
        
    *   Cancel reservations (subject to system rules).
        
*   **Business Rules**
    
    *   Booking limits per user.
        
    *   Capacity limits per table.
        
    *   Prevention of duplicate bookings.
        
    *   Configurable reservation restrictions.
        
*   **Email Notifications**
    
    *   Instant booking confirmation email.
        
    *   Reminder email sent 30 minutes before the reservation.
        
    *   Booking cancellation notifications (optional).
        
*   **Reporting**
    
    *   Generate booking reports.
        
    *   Export reports to **PDF** and **CSV** formats.
        

**Module 02: User Management**
==============================

A centralized user management system allowing administrators to efficiently manage all user accounts.

### **Features**

*   **User Creation**
    
    *   Add individual users manually.
        
    *   Bulk import users via CSV files.
        
*   **User Management**
    
    *   Edit user profiles.
        
    *   Delete inactive or unnecessary accounts.
        
    *   Search and filter users.
        
*   **Role-Based Access Control (RBAC)**
    
    *   Administrator
        
    *   Member
        
    *   Resident
        
*   **Authentication & Security**
    
    *   Secure password hashing.
        
    *   Password reset support.
        
    *   Automated welcome email containing login information.
